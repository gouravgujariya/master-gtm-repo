# Campaign Angles — the strategy menu

**Always SHOW this menu to the user in Step 2 (before sourcing anything)** and let them pick one or more —
and add their own. The **strategy is Eric's and stays the same**; this list is a reusable, extensible menu.

## The 3 always-included (from `skills/campaign-strategy`)
1. **Creative Ideas** — research each prospect's website → 3 specific use cases. Opens *"I had an idea for {{company_name}}…"*. Needs company-level AI personalization.
2. **New Hire** — people who started a target role in the last ~90 days (open to new tools, chasing quick wins).
3. **Lookalike** — companies similar to the client's best **case-study customers** (seed domains → AI Ark lookalike). ✅ built and proven.

## More angles (pick per client / test variations)
- **Competitor engagers** — people engaging with a competitor's LinkedIn posts (Apify).
- **Hiring signal** — companies actively hiring for a role = buying intent (Apify job scrape).
- **Tech-stack** — companies using (or missing) a specific tool. **Tool: TechSight** (free, no API key) —
  enrich the sourced company CSV with each domain's tech stack, then filter by the tech your client targets
  (e.g. "on Zoho/HubSpot/Shopify"). See `references/techsight-cli.md`. Great free qualifier on any list.
- **Tenure-based** — brand-new-in-role or long-tenured decision-makers.
- **Local / geo** — local businesses by category + location (bulk 12M CSV first, then Serper).
- **Firmographic** — filter by industry, size, funding, revenue (AI Ark company search / bulk 900K).
- **Content / podcast / association / funding / web-traffic / reviews** — see `skills/campaign-strategy` for the full pattern library.

Every angle maps to one **value-prop category**: make money · save time · save money · reduce risk.

## Custom / client angles (important)
- If the client has a **specific angle** or an **existing GTM strategy**, build a campaign plan around it and
  run it **alongside** the standard angles. **Append it to this file** so it becomes a reusable option.
- The user can add as many new angles as they want here to test different variations.

## How to run this step
1. Show this menu. 2. User picks one or more (or gives their own angle / existing strategy).
3. Write a 1-paragraph **plan per chosen angle** (who to target · AI/personalization approach · value prop).
4. **Confirm with the user.** 5. Only then proceed to sourcing.

> New here? `skills/campaign-strategy` generates a full tailored set of 15–25 angles from the client's
> website + ICP if the user wants a bespoke menu instead of / in addition to this standard one.
