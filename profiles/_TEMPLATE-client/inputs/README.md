# inputs/ — everything the client gives us

Drop all client-provided material here. These feed the ICP, strategy, lookalike seeds, and personalization.

- `questionnaire.md` — the onboarding answers (start here)
- case study documents / PDFs (named customers → lookalike seeds)
- pitch decks, one-pagers, brand/positioning assets
- existing customer lists or CRM exports
- call transcripts / kickoff notes

Nothing in here is generated by us — it's the raw input. Outputs go to `../lead-database/`.
